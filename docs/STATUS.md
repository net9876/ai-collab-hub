# AI Collab Hub — состояние на 2026-10-04

Отчёт для обсуждения дальнейших шагов. Репозиторий: `net9876/ai-collab-hub`
(private), локальный клон `C:\AI\collab`. Подробности — по ссылкам на `docs/`.

## 1. Что это

Общая рабочая память для нескольких AI-агентов одного человека. Агенты —
отдельные программы, которые ничего не знают друг о друге; хаб даёт им общее
состояние между сессиями:

- **проекты** — карточки, по которым раскладываются записи;
- **память** — проверенные факты (`verified`) и гипотезы, тело в Markdown;
- **решения** — ADR-подобные записи; новое решение может атомарно заменить старое;
- **задачи** — с атомарным захватом: из нескольких агентов выигрывает ровно один;
- **сообщения** — записки между агентами, с адресатом и тредами.

У каждой записи есть ID, время (UTC), проверенный автор (`owner/<агент>`),
номер ревизии и история. Перезаписи «молча» нет: обновление требует
`expected_revision`.

Правила для агентов и навыки живут в Git (`shared/RULES.md`, `skills/`), рабочее
состояние — в хабе. Агентам доступны только типизированные CRUD-операции
(21 инструмент в развёрнутой версии; ветка `feat/sessions-handoff` добавляет ещё 8 — сессии и передачу задач, всего 29). Выполнить команду, прочитать файл или достучаться до ноутбука
через хаб нельзя. Сообщения и задачи — это данные, а не приказы: агент обязан
спросить пользователя, прежде чем действовать по ним.

## 2. Как устроено

```
Ноутбук                                       Azure (eastus, rg-collab-prod)
Claude Code ─┐  Entra-токен из az               Container App (MCP, Python, scale 0..2)
Codex (app) ─┤  (кэш + задача обновления)  ──►   /mcp  /healthz  OAuth-эндпоинты
             │                                    │ managed identity (без ключей)
ChatGPT ─────┤  OAuth хаба (DCR+PKCE)             ├─ Table Storage: записи, история, OAuth
Claude.ai ───┘  вход через Entra                  └─ Blob Storage: тексты памяти
                                                  ACR Basic, Log Analytics
GitHub: код, правила, CI, ручной deploy (OIDC, без секретов)
Entra ID: API-приложение, login-приложение, GitHub deploy-приложение
```

- **Сервер:** Python, официальный MCP SDK 2.2 (протокол 2026-07-28, совместим с
  2025-11-25), Streamable HTTP, stateless.
- **Хранилище:** одна таблица и один blob-контейнер. Запись, её ревизия и ключ
  идемпотентности пишутся одной транзакцией. Конкурентность — через ETag.
  Поиск — по ключевым словам и метаданным, без полнотекстового индекса.
- **Доступ CLI-агентов** (Claude Code, Codex): токен Entra из `az login`.
  Клиенты ждут команду-помощник не дольше 10 секунд, а `az` на этом ноутбуке
  работает 20–30 секунд. Поэтому `scripts/mcp-headers.cmd` мгновенно отдаёт
  токен из локального кэша, а задача в Планировщике обновляет кэш раз в 5 минут.
  Журнал обновлений: `%LOCALAPPDATA%\ai-collab-hub\refresh.log`.
- **Доступ коннекторов** (ChatGPT, Claude.ai/Desktop): хаб сам работает как
  OAuth-сервер. Он регистрирует клиента (DCR), отправляет пользователя на вход
  в Microsoft и показывает страницу согласия. Затем выдаёт свой токен на 1 час
  и refresh-токен на 30 дней. Своей учётной записью в Entra хаб подтверждает
  себя через managed identity — секретов и Key Vault нет.
- **Кто допущен:** только Entra-аккаунты из списка `collab_principals`
  (сейчас один — владелец). Проверка идёт при входе и при каждом
  использовании токена.
- **Инфраструктура:** Terraform, два стека. `infra/bootstrap` — state-хранилище,
  Entra-приложения, GitHub OIDC. `infra/terraform` — всё остальное.
  `terraform plan` сейчас показывает «No changes».
- **Стоимость:** около $5–7 в месяц. Почти всё — ACR Basic (~$5). Container
  Apps укладывается в бесплатный грант, Storage — центы, логи ограничены
  0,2 ГБ в день.

Найдено и исправлено при реальном развёртывании (в тестах это не ловилось):

- **azuread:** каждый plan пытался удалить identifier URI API-приложения.
- **Container Apps:** Azure теперь создаёт профиль `Consumption` по умолчанию,
  и plan пытался его удалить.
- **Лимит 10 секунд на helper** у Claude Code и Codex.
- **GitHub OIDC:** subject в новом формате с неизменяемыми ID —
  `repo:owner@id/repo@id:...`.
- **SDK таблиц:** удаление несуществующей строки считается успешным,
  поэтому одноразовые коды сделаны через отметку с ETag.
- **Entra id_token без `oid`:** нужен scope `profile`, не только `openid`.
- **Страница согласия:** CSP `form-action 'self'` блокировала в Chrome
  возврат в claude.ai после Allow; теперь разрешён ровно адрес клиента.

## 4. Что ещё не подтверждено или требует действий

1. **PR фазы 1 (сессии/передача задач)** ждёт ревью; деплой — только по команде
   владельца (`docs/runbook.md` §8). PR #6 смержен 2026-10-04; `main` совпадает с
   развёрнутым серверным кодом.
2. **Claude.ai:** переподключить коннектор (Settings → Connectors → Collab →
   Connect). Чтобы найти причину сброса, стоит логировать исходы `/token`.
3. **Codex не прочитал** «Re: ping» и «ping from Claude Code» — достаточно
   попросить его `Check my collab inbox`.
4. **Холодный старт.** Приложение засыпает при простое; первый запрос после
   паузы может не уложиться в таймаут клиента (так было у ChatGPT). Вариант:
   `min_replicas = 1` — примерно +$3–6 в месяц. Решение за владельцем.
5. **Ноутбук.** Рекомендации, без изменений системы:
   - один браузер вместо трёх (Chrome, Edge, Opera);
   - закрывать лишние окна VS Code;
   - перезагрузка раз в неделю;
   - если Explorer снова грузит CPU — проверить расширения оболочки и OneDrive;
   - по возможности добавить RAM.

## 5. Как пользоваться

Открыть агента в `C:\AI\collab`:

- **Claude Code:** `wt -d C:\AI\collab pwsh -NoExit -Command claude`.
- **Codex:** чат в проекте `C:\AI\collab` в приложении ChatGPT.

Фразы:

- `Get context for project ai-collab-hub from collab` — начать работу.
- `Record a decision in collab: …` / `Add a verified memory in collab: …`
- `Create a task in collab: …`, `Claim task <id>`, `Complete it with evidence`
- `Send a message in collab to codex: …`, `Check my collab inbox`
- `Archive project <slug> in collab` (через `project_update`)

Сессии и передача работы между клиентами (после деплоя фазы 1): `docs/workflow.md`.
План развития (фазы 2–3): `docs/roadmap.md`.

Проверка здоровья: `claude mcp list` (collab: Connected),
`Get-Content $env:LOCALAPPDATA\ai-collab-hub\refresh.log -Tail 5`.

## 6. Отложено (в бэклоге хаба, приоритет low)

- отдельная Entra-идентичность для каждого агента (сейчас метка агента
  самозаявленная);
- выгрузка и резервная копия данных хаба;
- приватная сеть (VNet и private endpoints) и семантический поиск
  (Azure AI Search).

## 7. Вопросы для обсуждения

- Нужен ли ChatGPT с записью или достаточно чтения? Это зависит от того, что
  разрешает план ChatGPT.
- Как будет устроен процесс: какие задачи кто берёт, должны ли агенты сами
  писать итоги в хаб в конце каждой сессии.
- Стоит ли сэкономить $5 в месяц на ACR, или текущая стоимость приемлема.
- Когда нужен второй пользователь, если вообще нужен: модель workspace уже
  поддерживает изоляцию.
